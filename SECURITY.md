# Security policy

This project is an unverified preview. Do not place secrets in GitHub issues, commits, or screenshots.

If a token is accidentally published, revoke the affected Twitch authorization immediately, delete local token files, and obtain new access credentials. Removing a secret from the latest commit is not sufficient if it remains in Git history.

Use GitHub private vulnerability reporting if enabled on the repository, or contact the maintainer privately. No security support SLA is guaranteed.
